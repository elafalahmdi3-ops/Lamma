# لمّة — ألعاب جماعية للجمعات

موقع ألعاب جماعية بالعربي: شخص ينشئ غرفة، والباقون يدخلون من جوالاتهم بالرابط أو برمز من 4 أرقام. المزامنة لحظية، والخادم هو اللي يحدد بداية الجولات ويقبل الإجابات ويحسب النقاط.

## الألعاب (٢٤ لعبة في ٥ أقسام)
- **⚡ سرعة ورد فعل:** لا تستعجل!، ضغط جنوني، عكس السهم، ألوان مخادعة، اقلبها وسبقهم
- **🧠 ذاكرة:** وش تغيّر؟، مين اختفى؟، مين ظهر أول؟، احفظ الرقم، تتابع الألوان
- **👀 ملاحظة وتقدير:** وين الكرة؟، ظل مين؟، كم عددها؟، إحساس الوقت، كمّل النمط
- **📚 معلومات وذكاء:** تحدي المعلومات، صح ولا خطأ؟، خمّنها بالإيموجي، الكلمة الدخيلة، حسبة سريعة
- **🫶 جماعية وتعاون:** قلب واحد، لا تتشابهون!، مع الأغلبية، مين فينا؟

طرق الفوز تختلف حسب اللعبة:
- **أول إجابة صحيحة:** في أغلب الألعاب.
- **الأسرع رد فعل:** في «لا تستعجل!»، والزمن يُحسب على الخادم مع تعويض الاتصال.
- **الأقرب للجواب:** في «كم عددها؟» و«إحساس الوقت».
- **أكثر عدد ضغطات:** في «ضغط جنوني».
- **بدون نقاط:** في الألعاب التعاونية والاجتماعية.

المضيف يقدر يختار لعبة وحدة أو لعبة عشوائية، أو يرتب بطولة من عدة ألعاب، أو يبدأ «بطولة سريعة» من ٥ ألعاب عشوائية.

## التشغيل محليًا
يحتاج Node.js 18 أو أحدث، ولا يحتاج أي مكتبات (`npm install` غير ضروري).
```
node server.js
```
ثم افتح http://localhost:3000. للتجربة بين أجهزة في نفس الشبكة افتح `http://<IP جهازك>:3000` من الجوالات.

## النشر على Cloudflare (مجاني) — الطريقة المقترحة
⚠️ **Cloudflare Pages ما يشغّل اللعبة.** Pages يعرض صفحات ثابتة فقط، واللعبة تحتاج خادمًا للمزامنة بين الأجهزة. استخدم **Workers** بدله، والمشروع جاهز له: الملفات `worker.js` و`wrangler.toml` تشغّل كل غرفة كـ Durable Object.

1. ارفع محتوى المجلد إلى مستودع جديد على GitHub. لازم يكون `wrangler.toml` في جذر المستودع، مو داخل مجلد ثاني.
2. في لوحة Cloudflare: **Workers & Pages ← Create application ← Import a repository**، واختر المستودع.
3. اسم المشروع لازم يكون **lamma**، نفس الاسم المكتوب في `wrangler.toml`. خلّ أمر النشر على الافتراضي `npx wrangler deploy`، واضغط **Save and Deploy**.
4. الرابط يكون مثل `https://lamma.<اسمك>.workers.dev`.

## بديل: النشر على Render
1. ارفع هذا المجلد إلى مستودع جديد على GitHub (من الموقع: New repository ← Upload files ← اسحب الملفات كلها مع المجلد `public`).
2. ادخل render.com ← سجّل بحساب GitHub ← **New ← Web Service** ← اختر المستودع.
3. الإعدادات:
   - Runtime: **Node**
   - Build Command: اتركه فارغًا (أو `echo ok`)
   - Start Command: `node server.js`
   - Instance type: **Free**
4. اضغط Create. بعد دقيقتين تقريبا يعطيك رابطًا مثل `https://lamma-xxxx.onrender.com`، وهذا رابط اللعب.

ملاحظات: الخطة المجانية في Render «تنام» بعد 15 دقيقة بدون استخدام، وأول فتح بعدها يأخذ قرابة 30–50 ثانية. الغرف محفوظة في ذاكرة الخادم، فإذا أعيد تشغيله تضيع الغرف الحالية. يعمل الموقع أيضًا على أي استضافة تدعم Node وWebSocket مثل Railway وFly.io، أو على VPS.

## شاشة العرض
افتح `/screen/<الرمز>` على آيباد أو تلفزيون لتعرض اللعبة بشكل كبير، ويبقى كل لاعب يشارك من جواله. ويمكن إنشاء الغرفة نفسها كشاشة عرض، وفي هذه الحالة يتحكم المضيف بدون ما يلعب.

## الوضع التجريبي
من الصفحة الرئيسية ← «وضع تجريبي على جهاز واحد». يشغّل نفس محرك اللعبة داخل المتصفح بدون خادم، وهو للتعرّف على الألعاب فقط وليس لعبًا جماعيًا.

## البنية
- `server.js`: خادم HTTP + WebSocket (مكتوب يدويًا في `ws.js` بدون مكتبات).
- `public/engine.js` و`public/more.js`: محرك الغرف والألعاب ومحتواها، وهو المرجع الموثوق. يعمل على الخادم، ونفس الملفات تعمل في الوضع التجريبي.
- `public/app.js` و`core.js` و`games.js` و`sound.js`: الواجهة والأصوات (مولّدة بدون ملفات خارجية).
